# float reader 
用浮窗显示pdf文件中文内引用的preview的pdf阅读器

# 期待解决的问题
阅读电子书时，常因为文中出现的文内引用的原因，需要不断地跳转到不同的页码。在当前阅读器中，可以自定义每一个文内引用的preview的具体视图，然后当遇到具有连接跳转功能的链接的时候，可以通过鼠标悬浮直接浏览自定义的preview视图，进一步可通过点击视图固定该preview。避免pdf页码跳转的问题。

# 如何安装
前提条件
1. 安装了cargo, git 
2. 具有适用于当前平台的libpdfium的动态连接文件，比如#[pdfium-binaries](https://github.com/bblanchon/pdfium-binaries)

步骤：
1. 克隆当前仓库
2. 将libpdfium.so文件放置于asset文件夹下，替代现有文件。
3. cargo build --bin float_reader

# 如何使用
1. 打开pdf文件。
  - 通过在输入框输入pdf文件的路径
  - 通过将pdf文件拖拽到窗口中
2. 待文件加载后，即可开始预览。这里预览有三种选项，如下。
  - 单页
  - 双页
  - 横向预览。即所有pdf页面放置在同一行上，为此右上角第一个勾选框，勾选后，可使用鼠标完成横向滚动（触摸板滚动被限制）。
![read_mode](/asset/ui/read_mode.gif)
3. 当显示的比例足够大的时候，页面中会出现灯泡按钮以及红框。前者表示此处对应为被引用的某个位置（因此如果没有被引用，不会被显示），后者表示可以触发位置跳转的作用区域，可以通过勾选右上角第二个勾选框去掉红框的显示。
![ref position](/asset/ui/ref_position.png)
4. 点击灯泡按钮出现的选择框与对应的连接上的显示的预览图相同。可通过修改选择框来修改预览内容。同时，修改选择框也会修改连接的跳转动作的目的地。可通过点击固定预览图。如果存在某引用的预览图时，再次悬浮指针到连接该引用的链接上，则不会出现预览图。
![resize_preview](/asset/ui/resize_preview.gif)
5. 可以保存当前设置的预览信息，点击上方的save link info按钮，即可保存为同目录下同名的pdf.json文件。下次再次打开的时候可以直接使用上次保存的信息。
# 注意事项
该阅读器无法加载或创建对pdf文件的任何注释。
